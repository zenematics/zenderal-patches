# Bestiary — enemy taxonomy, tiers and bosses

Reference for Enderal's enemies: how the game encodes creature families, difficulty and bosses, and
how to classify its NPCs programmatically without being lied to by the record fields that *look*
authoritative.

The one-sentence thesis first: **nothing in Enderal scales to the player.** There are **zero
LeveledNpc (LVLN) records** in either tree, and every one of the 1,816 base + 1,052 FS NPC records
uses a **fixed level** (`MutagenObjectType: NpcLevel`) — not one uses `PcLevelMult`. **[verified]**
Enderal's world is hand-placed, statically-levelled actors; difficulty is geography, not a
formula. (The other half of that story — the abandoned encounter-zone system — is in
[`world-and-dungeons.md`](world-and-dungeons.md).)

Counts taken **2026-08-13** against `reference/base/` (Enderal SE 2.0.12.4), with NPC template
chains resolved and English-only strings — see [`factions.md`](factions.md) for why both are
mandatory.

## How to classify an enemy (and how not to)

The reliable pipeline, in order **[verified]**:

1. **Resolve the `Template:` chain.** 566 of 2,251 merged NPCs inherit record blocks from a
   template when the matching `Configuration.TemplateFlags` bit is set (`Factions` on 441 of them,
   also `Stats`, `Keywords`, `Script`…). Chains are multi-level
   (`_17E_Arp01_Range1500 0B5270` → `_18E_ArpSchamane_Aggressive 0B5266` → `_17E_MQ08ArpSchamane
   0B5277`). Skip this and ~20% of answers are wrong.
2. **Match a `Creature_*Faction`.** 47 purpose-built taxonomy factions, a near-contiguous FormID
   block `046E62–046EB4:Skyrim.esm` plus strays (`Creature_FourtuskFaction 046ADD`,
   `Creature_MyradTamedFaction 146721`…). Shape: a self-ally relation, `HiddenFromPC`,
   nothing else — they exist *only* to say what kind of creature this is. This is the best key in
   the game.
3. **Else a coarse bucket faction**: `BanditFaction 014C6F` (318 resolved members),
   `UndeadFaction 005104` (289), `NehrimArmyFaction` (53), `SpiderFaction 018724`,
   `StarlingBotFaction`, `MagicCreatureFaction`, `PossessedFaction`, FS's `ArpFaction 02F436`.
   (`AnimalFaction 046E73` layers *on top of* the `Creature_*` tags — treat it as coarse.)
4. **Else fall back to the German EditorID stem** (decoder ring below).

Tier = `Configuration.Level.Level`. Boss = the `ActorTypeBoss` keyword. XP = the `_00E_EPOnDeath`
script. All three below.

### Fields that lie

| Field | Why not |
|---|---|
| **Race** | Mostly unrenamed vanilla shells: `DraugrRace 000D53` covers every Lost One variant, `FalmerRace 0131F4` = Arps, `WerewolfBeastRace 0CDD84` = Vatyr, `HorseRace` = Myrads, the `Dwarven*Race`s = Starling constructs, `MammothRace` = Fourtusk/Tyarge **[verified]** |
| **Class** | Actively misleading on creatures — the Vatyr's class is `TrainerBlockExpert`, the Arp Shaman's is `TrainerIllusionMaster`. Only humanoids get meaningful `CombatBarbarian`/`EncClass*` values **[verified]** |
| **CombatStyle** | 121 records, all but 3 vanilla-named (`csWerewolf`, `csDraugrMeleeLvl1`) — encodes fighting archetype, not family |
| **VoiceType** | Vanilla `Cr*Voice` — decent secondary signal, coarser than the factions |
| **`Unique` flag** | 126 merged carriers, and only 24 of them are bosses — the rest are bards, dancers, Myrad wardens and companions **[verified]** |

### Races, for completeness

117 base / 51 FS RACE records. The playable races sit on vanilla slots with renamed display names
**[verified]**: Imperial=**Endralean**, Nord=**Arazealean** (`NordRace` = Half Arazealean),
Redguard=**Qyranian**, Breton=**Kiléan**, HighElf=**Half Aeterna**, DarkElf=**Aeterna**,
WoodElf=**Starling**, plus `_00E_LeorRace`=Leoran. `ArgonianRace`, `KhajiitRace`, `OrcRace` and the
dragon races exist as vestigial leftovers no Enderal NPC uses. FS adds pure size-tier variants
(`VatyrRaceLarge/Giant`, `_00E_StoneGolemRace{Large,Big,Bigger,Giant,Colossal}`) differing only in
`Height`. **[verified]**

## The `_NNE_` tier convention

Generic-enemy EditorIDs encode designer intent:

```
_<NN>E_<GermanStem><Variant><Role>_<BehaviorSuffix>
_05E_Bandit03Ranged_Aggressive     _16E_LostOneBlackVer1_Range1200     _15E_VatyrVaBoss
```

- `NN` = intended encounter level. 920 merged NPCs carry a non-`00` prefix; tier anchors sit at
  5/10/20/25/30/40/45 (level 30 is the biggest combat bucket at 206 NPCs). **[verified]**
- **`_00E_` is a namespace, not level zero** — 1,111 base NPCs use it for quest/town/unnamed-tier
  records.
- **The prefix agrees with the actual `Level` field only 78% of the time** (721/920); the rest
  drifted in rebalancing, sometimes far (`_50E_NQBounty02_RalafCrocco` is level 20,
  `_29E_UniWissenschaftler` is level 10). **`Configuration.Level.Level` is ground truth; the
  prefix is the designer's label.** **[verified]**
- Behavior suffixes map to real fields **[verified]**: `_Range<NNNN>` → `AIData.Attack`/`WarnOrAttack`
  = NNNN exactly; `_Aggressive` → `AIData.Aggression`; `_Ambush`/`_Patrol` → package variants;
  `Bogen`/`Ranged`/`Mace` → loadout; `_NoRespawn` → no `Respawn` flag; `Var`/`Ver`/numbers →
  cosmetic variants.

`Skelett` skeleton (`SkelettBogen` archer) · `Magier` mage · `Hexe` witch · `Besessene(r)`
possessed · `Verlorener` lost (one) · `Grabwaechter` tomb guardian · `Ahnengeist` ancestral spirit ·

`Baer`/`Braunbaer`/`Eisbaer` bear/brown/ice · `Hoehlentroll`/`Eistroll` cave/ice troll ·
`Schneewolf` snow wolf · `Fuchs` fox · `Ratte` rat · `Mooskrabbler` moss crawler · `Frostkrabbler`

## XP is per-actor data, not a formula

Enderal's kill XP is the `_00E_EPOnDeath` script's literal `RewardExp` int property, present
(after template resolution) on **906 NPCs**. **[verified]** There is no level-based formula to
tune — a difficulty or XP patch edits per-actor integers. The values are also the game's own
difficulty opinion, finer-grained than level: a level-50 Triceratops pays 250 while the level-50
Ash Widow pays 3000. The script is also a solid "is a killable enemy" filter — town NPCs don't
carry it.

## Bosses and uniques

The reliable boss marker is the **`ActorTypeBoss` keyword `090CA9:Skyrim.esm`** — it is what
`_00E_CombatSoundtrackScript` reads to switch to boss combat music, so it is *functionally* load-
bearing, not just descriptive. **[verified]** After template resolution it sits on **91 NPCs** (85
base-defined, 6 FS-new). Secondary signals: `BossesFaction 03C755` (49 members), `Boss`/`Uni`/
`NQBounty` EditorID infixes. The `Unique` flag is noise (see "Fields that lie").

## Other record facts worth knowing

- **DeathItems are vanilla-named LVLIs re-pointed at Enderal loot**: `DeathItemDraugr 03AD7F` on
  104 NPCs, `DeathItemTroll`, `DeathItemBear*`, plus a handful of `_00E_*` additions. A Skyrim
  loot mod that edits `DeathItemDraugr` edits the *right FormID with the wrong assumptions* about
  what's in it. 240 base NPCs carry one. **[verified]**
- Creature "skins" are `WornArmor:` ARMO links; innate abilities are `ActorEffect:` lists (300
  NPCs). `LeveledSpells/` holds exactly 2 records (`_26E_SpellListLongRange`/`ShortRange`).
  **[verified]**
- Nearly every combat actor carries two scripts: `_00E_CombatSoundtrackScript` (552 base — combat
  music, *not* a boss marker by itself) and `_00E_EPOnDeath`. **[verified]**
- `_00E_CharacterTemplate_<Race>_<Sex>_<NN>` (31 records) are the appearance-template pool for
  civilian NPCs — TPLT parents, not enemies. **[verified]**

## What this means for patching

1. **Enemy-overhaul mods have nothing to inject into.** No LVLN lists, no encounter-zone scaling —
   a Skyrim mod that distributes new enemies via leveled actor lists is inert here. Adding an
   enemy means placing actors or patching the specific NPC records.
2. **Difficulty mods must edit per-actor data** — fixed `Level`, `HealthOffset`, and `RewardExp`
   integers on 906 actors. There is no global scaling curve to bend. Conversely, a "de-level the
   world" mod is meaningless: Enderal already is one.
3. **Filter/distribution logic (SPID, patches) should key on `Creature_*Faction`** — it is the
   one purpose-built, complete taxonomy. Anything keyed on Race or Class will mis-bucket the
   entire bestiary.
4. **Touching a boss?** Preserve the `ActorTypeBoss` keyword — it drives boss music via
   `_00E_CombatSoundtrackScript` — and remember 6 of the 91 are FS records, so override FS's copy.
5. **Template chains make partial overrides fragile.** Overriding a template parent silently
   changes every child inheriting that block; overriding a child that inherits (say) `Factions`
   and adding a `Factions:` list does nothing unless the `TemplateFlags` bit is also cleared.

## Checklist for an enemy-touching patch

- [ ] Did you resolve the `Template:` chain before reading factions/keywords/stats?
- [ ] Are you keying families on `Creature_*Faction`, not Race/Class?
- [ ] Did you read `Configuration.Level.Level` rather than trusting the `_NNE_` prefix?
- [ ] If the record has an FS override, did you start from FS's copy?
- [ ] If you changed a boss, is `ActorTypeBoss 090CA9` still present?
- [ ] If you changed XP or difficulty, did you touch `RewardExp` (the actual currency), not just
      health/level?
