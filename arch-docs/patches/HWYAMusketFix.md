# HWYAMusketFix → `Zenderal - HWYA Musket Fix.esp`

**Ships:** an ESL with 3 PROJ overrides, Gravity 0.001 / 0.000002 → 0. Also changes Flame Shot's own ball
(`ZP_FlameShot_MusketBallProj 000800:Zenderal - Flame Shot.esp`) the same way, in
`src/FlameShot/tools/01-build-flame-shot.py`. Generated by `tools/01-build-hwya-musket-fix.py`.

## Problem (2026-10-29)

After [Hit Where You Aim](ThirdPersonSpellAim.md) was installed, aiming a musket in third person bent
the player backwards with the barrel pointing at the sky. The curator was not looking up.

## Cause

HWYA 1.1.2 also hooks the player's aim pitch (`PlayerSetAimPitchHook::PlayerGetAimPitch` in its
`Hooks.cpp`, the angle the 3rd-person aiming pose uses) during the bow/crossbow draw states. With
automatic pitch correction on (the Easy preset), it feeds `BallisticSolver::Solve` the equipped ammo
projectile's `speed` and `gravity × fWorldGravity`. Any gravity above 0 goes to its quartic. It keeps
a root only if the rebuilt launch speed matches the projectile speed within 0.1%.

The list's gun balls are very fast and almost gravity-free:

| PROJ | Speed | Gravity |
|---|---|---|
| `OLM_proj_ball 002F9E:OrdoLegionisMuskets.esp` (Musket Balls) | 60000 | 0.001 |
| `OLM_proj_ballminie 00F5DF:OrdoLegionisMuskets.esp` (Rifled Bullet) | 70000 | 0.001 |
| `0ProjBullet 000808:DAR Rifles.esp` | 100000 | 0.000002 |
| `ZP_FlameShot_MusketBallProj 000800` (copy of Ordo's ball) | 60000 | 0.001 |

The solver was compiled offline (MSVC, its header unchanged) and run over 100–10000 units of distance
and ±400 of height. With speed 60000 and gravity 0.001 it returns **pitch +90.00°** at almost every
distance: the flat root is lost to floating-point error and only the high arc survives. Arrows
(4300 / 0.35), bolts (5600 / 0.35), the pistols (5555 / 0.11) and Ordo's scrap shot (50000 / 0.5) all
solve correctly. The failures are speed ≥ ~4300 with gravity ≤ ~0.001, and speed ≥ 15000 with
gravity ≤ ~0.03.

## Fix

At Gravity exactly 0, `Solve` takes `SolveLinear`, which is exact. Each override is the winning record
copied verbatim with its `Gravity:` line dropped (Spriggit omits a zero gravity). Ordo's winner is the
*Muskets of the Enderal* copy (`ol_ProjectileBB.nif`, = `reference/mods/OrdoEnderal`). No other list
plugin overrides these PROJs. In play, 0.001 × gravity over a 60000-unit/s flight is no drop anyway.
HWYA's launch hook used the same solver as a fallback, so the shot itself is safe too.

Load after `DAR Rifles.esp` and `OrdoLegionisMuskets.esp` (it masters both). It sits right after
`Zenderal - Flintlock Overhaul.esp`. Flame Shot's ball is rebuilt in Patch Collection's copy
(4 bytes differ: the float).

The alternative was HWYA's Medium/Hard preset or `iPitchCorrectionMode` ≠ automatic. That gives up
automatic drop compensation for bows, so it was not chosen.

Backups: `E:\Zenderal-backups\HWYAMusketFix\` (Ultra's modlist/plugins/loadorder, Patch Collection's
old Flame Shot).
