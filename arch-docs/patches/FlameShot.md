# FlameShot

- **Source:** `src/FlameShot/` — YAML generated by `tools/01-build-flame-shot.py`; never hand-edit it
- **Ships:** `Zenderal - Flame Shot.esp` (ESL) + `Scripts/_00E_A1_FireArrowSC.pex`
- **FormID block:** `0x800–0x801`
- **Built:** 2026-10-16. Deserialize and compile are clean. **Not yet verified in xEdit or in game.**

## What it does

The Rogue talent **Fire Arrow** (Shout `_00E_A1_Firearrow 05C233` → spell `05C24D` → MGEF `05BD36`)
is renamed **Flame Shot** and now works with muskets.

**The bug [verified from SureAI's source].** `_00E_A1_FireArrowSC.OnEffectStart` adds N
`_00E_A1_FireArrowAmm 0670EC` (EGO-overridden) and **force-equips them**. A crossbow-type weapon
(all 14 of Ordo Legionis' muskets are `AnimationType: Crossbow`) cannot fire arrows. The script ends
early only through `OnPlayerBowShot`, so with a musket it sits out the full duration. On finish it
re-equips `amOldAmmo`, but `GetEquippedAmmo()` only searches `_00E_A1_FirearrowAmmoFormlist 13E955`,
which holds arrows only. With musket balls equipped it finds nothing and calls `EquipItem(None)`, so
the musket is left with no ammo.

**The fix:**

- **`0x801 ZP_FlameShot_MusketBall`** "Flame Musket Ball" is a copy of Ordo's Musket Balls `002F9D`.
  Changes: value 0, and the pickup/putdown sounds re-pointed from `Dawnguard.esm` (an empty stub in
  Enderal) to the fire arrow's own sounds.
- **`0x800 ZP_FlameShot_MusketBallProj`** is a copy of Ordo's `OLM_proj_ball 002F9E`. Changes: its
  explosion is `_00E_A1_FireArrowExp 066891`, and `CanBePickedUp` is dropped. That explosion carries
  `_00E_A1_FireArrowEnchantment 06722A`, whose magnitude the script already sets per talent tier, so
  the fire damage (and Swashbuckler's bonus blast) comes with the projectile. The cost is Ordo's own
  impact explosion `007ED3`, which this ball no longer plays.
- **Script** (`; ZP`): with `GetEquippedItemType(1) == 12` (crossbow) it hands out the musket ball
  instead of the arrow. All the other `_00E_A1_FireArrowAmm` uses now go through `amShotAmmo`, and it
  never equips a None old ammo.
  - The new property `ZP_FlameShotMusketBall` is filled by this plugin's override of MGEF `05BD36`.
    No other plugin in the list touches that record (live scan, 2026-10-16).
  - Without the plugin, the property is None and the talent behaves as SureAI's version did.
  - No other mod ships a loose `_00E_A1_FireArrowSC.pex`.
- **`13E955`** = EGO's list plus the 8 bolt-type ammos in the list (EGO's 3 Xion bolts, Crossbows' 2,
  Ordo's Musket/Minié Balls and Blunderbuss Scrapnel), so the old ammo comes back. DAR Rifles' two
  bolt ammos are left out because their recipes are hidden.
- **Renames:**
  - "Flame Shot" on SHOU `05C233` (EGO), SPEL `05C24D` (EGO) and MGEF `05BD36`.
  - "Talent: Flame Shot" on PERK `069CD3`/`0BFA3E`/`0BFA3D`, ACTI `0671F7`, and MESG `069D6E` (EGO's
    copy was titled, untranslated, `Talent: Feuerpfeil`).
  - Descriptions mention the musket balls, as does Swashbuckler's `14334A` (EGO).
  - The ammo itself keeps the name "Fire Arrow".

**Winning sources (2026-10-16 scan):** EGO for `05C233`, `05C24D`, `069D6E`, `14334A` and `13E955`;
base Enderal for the rest. `0670EC` and `0670DC` (EGO / Pretty Armory) are not overridden here.
Re-run the generator after any EGO update.
