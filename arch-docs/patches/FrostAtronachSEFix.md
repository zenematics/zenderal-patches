## What it does

**Ice Elementals rendered completely black** (reported 2026-10-12). Enderal's Ice Elementals (`_14E_IceElemental 0E11B1` and kin) are `AtronachFrostRace 0131F6` → skin `SkinAtronachFrost 05B2E7` → `NakedAtronachFrost 05B2E8` → `Actors\AtronachFrost\Character Assets\AtronachFrost.nif`. `Frost Atronach SE` (Nexus 171447 v1.0.0) replaces it, but **every NIF it ships is Skyrim LE format** (BS stream 83, `NiTriShape`) — the game's own copy is stream 100 `BSTriShape`. Textures (DXT1/DXT5, full mips) and shader (multi-layer parallax, type 11, same as vanilla) were fine. `src/FrostAtronachSEFix/tools/01-convert-frost-atronach.py` converts both meshes to SE with **PyNifly** (`tools.json` `pynifly`; GitHub BadDogSkyrim/PyNifly V29.1.0 — CAO is Nexus-only) and asserts the read-back: block layout identical to vanilla, geometry/triangles/binds/partitions/shader fields/texture slots unchanged; weights cut to SE's 4 influences and renormalised (450 verts had 5–6, max 4.3% dropped). **That alone did NOT fix it** — still black in game. Real cause: the author's TEXTURES vs the shader. The mesh is multi-layer parallax (type 11), whose outer diffuse alpha sets how much inner layer shows; the author's outer `T_IceGolem_Base_color1` averages alpha **11** (vanilla `FrostAtronachOuter` 113) over an inner `T_Ice_BaseColor2` of RGB 20/37/37 (vanilla 53/81/93), so it rendered as almost pure inner layer = black. The generator therefore writes the **plain lighting shader** (type 0, SLSF2 `MULTI_LAYER_PARALLAX` cleared; `--multilayer` restores the author's) — **verified in game 2026-10-12, textured**. Ruled out on the way: `AbAtronachFrostFX`'s effect shader `AtronachFrostFXS 05FB82` (fill `effects/vaportile01.dds`, which RUSTIC DAEDRA replaces with a copy statistically identical to vanilla's). Its LE `skeleton.nif` (LE Havok ragdoll, bone names identical to vanilla) outranked XPMSSE's, so the fix mod also ships **XPMSSE's** skeleton verbatim — the original mod's files are untouched. Not committed (author's meshes). Sorts directly above `Frost Atronach SE`. Built and enabled in Alpha 0.5 2026-10-12. **A scan of the profile found LE-format (stream 83) NIFs in ~55 enabled mods**; most are statics/effects that SE tolerates, but skinned creature meshes are the suspect class — Flame Atronach SE, Spider SE, Trolls SE, Spriggans SE, Bears of the North, Iron Golem, Enderal Donkey — unchecked in game.
