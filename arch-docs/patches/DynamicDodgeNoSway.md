## What it does

Attack-cancel dodges play Dynamic Dodge's normal step dodge instead of its on-the-spot "sway". Dynamic Dodge (Nexus 79598, `TK Dodge RE-0.55-rc3` OAR set) ships `70110–70144` (weapon/direction step dodges) and a mirror set `70210–70244` = same conditions **+ `IsAttacking`** at higher priority (the sway). The release ships 20 `user.json` files — an OAR `user.json` REPLACES its submod's `config.json`, so each is the author's config verbatim + `"disabled": true` — and adds no file the author ships. **The cancel itself lives in TK Dodge RE, not Dynamic Dodge**: `SKSE/Plugins/TK Dodge RE.ini` `EnableDodgeAttackCancel` (the DLL reads it as `enableDodgeAttackCancel`); it stays `true`. Generated by `src/DynamicDodgeNoSway/tools/01-disable-sway-submods.py` from the installed mod (asserts every disabled submod is `IsAttacking`-gated and no `701xx` one is). **Verified in game 2026-10-05.**
