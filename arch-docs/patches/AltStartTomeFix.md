## The report

A player (2026-11-16) found "Spell Tome: Psionic Push (Rank I)" in the starting chest at Jespar's camp. The spell
worked, but its description read *"This spell is no longer used in the Gameplay Overhaul. This is caused by not
starting the game with the mod…"*. They had never seen the spell anywhere else.

## Cause

EGO renumbers the Psionic Push line:

| | Spell | Tome |
|---|---|---|
| Base Enderal Rank I | `06FF25:Skyrim.esm`; EGO keeps the record but replaces its description with the "no longer used" text and sets BaseCost 999 | `01E8DF:FS` (`_05E_FS_Spell_PsionicPush`), not overridden by EGO |
| EGO's Rank I | `06FF26:Skyrim.esm` (base Rank II) | `01E8E2:FS` (`_30E_FS_Spell_PsionicPush`); EGO's override names it Rank I and teaches `06FF26` |

EGO took `01E8DF` out of every loot and trader list it overrides. A master-aware binary scan of the live Ultra load
order (every winning LVLI, CONT, NPC_, FLST, REFR and ACHR, 2026-11-16) found the old tome in only two winners:

- `AltStart_CampChest 000800:Alt Start - Jespars Camp.esp`: Juno's *Alternate Start at Jespar's Camp - Zenderal
  Compatible* (Enderal Nexus 1152). This is the starting kit chest (65 entries).
- FS's own `_00E_PhasmalistApparition_SpellBooks 00DB60` form list. It was not looked into and is untouched.

## Fix

Juno's chest verbatim, with that one entry pointing at EGO's Rank I tome `01E8E2:FS`. Generated by
`python -I src/AltStartTomeFix/tools/01-build-alt-start-tome-fix.py` from
`reference/mods/AltStartJesparsCamp/` (serialized 2026-11-16). The generator asserts exactly one line changes.
Players who already learned `06FF25` keep it, and it still works.

**After an Alt Start update:** re-serialize it into `reference/mods/AltStartJesparsCamp/`, then rerun the generator.
The generator refuses to run if the chest already carries `01E8E2`.
