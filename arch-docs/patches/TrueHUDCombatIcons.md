## What it does

For Honor Reforged's status icons drawn **inside TrueHUD's info bar** instead of by SIF above the head: incoming-attack arrows on the matching side of the bar, one priority icon (unstable > stagger > parry > shield-flip > block-slide knockdown cooldowns) on the right — by default inline as `[bar][right arrow][status]`, the status icon moving up to the bar when no right attack is incoming (`reserveRightArrowSlot` keeps the gap); `"statusStyle": "circle"` restores the first design, the status icon in a drawn circle at the bar's right end. Mechanism: TrueHUD 1.1.9 creates each bar as `_root.TrueHUD.TrueHUD_MainVisibilityWidgets.<actor ObjectRefHandle native value>` (`attachMovie("TrueHUD_InfoBar", key)`), so a `HUDMenu::AdvanceMovie` vtable hook (vfunc 5) finds it and adds child clips — they inherit the bar's position, distance scale and fade; layout comes from `Bars.HealthBar.Frame.getBounds(bar)` and `Indicator` each frame (TrueHUD animates width). **SIF icon `.swf`s have an EMPTY stage** — each only exports one sprite (`ExportAssets`, name = the SIF rule's `label`, e.g. `leftLight`, `Unstable`), which SIF imports by name; `loadMovie` alone draws nothing (the first build showed the circle and no icons). So each rule names its `symbol`, and the plugin `loadMovie`s the file then `attachMovie(symbol)` on the loaded clip (resolves from that file's library — TrueHUD's own load-then-attach), re-centred from the sprite's bounds. Whichever FHR icon set wins is used; Vel'dun's replacer keeps FHR's export names. No call into TrueHUD.dll — a TrueHUD update that renames clips draws nothing rather than crashing. Rules = FHR's SIF conditions, in `data/SKSE/Plugins/ZenTrueHUDCombatIcons.json` (re-read on every save load, so layout tunes without restart); all 13 FormIDs verified by type (MGEF/KYWD) against the binaries. Ships `{"rules": []}` copies of FHR's eleven `SKSE/Plugins/SIF/*.json` to stop the duplicate SIF icons — **must sort above For Honor Reforged**, and non-target enemies (no info bar while TrueHUD's display modes are Never) get no icons. Build: `build.cmd` (shares the CommonLibSSE-NG clone in the repo-root `lib/CommonLibNG`). Log: `…\My Games\Skyrim Special Edition\SKSE\ZenTrueHUDCombatIcons.log`.
