# RaySensePriority

- **Source:** `src/RaySensePriority/`
- **Ships:** **no plugin** (50 OAR `user.json` files)
- **FormID block:** none

## What it does

Curator's taste: RaySense Cover Animation (Nexus 175504) and both RaySense wall-lean mods —
Simple Wall Lean (176847, by wowmigod) and Sonder's Raysense Wall Leaning (188857) — win over
every other OAR set whenever their RaySense conditions are true.

| Mod | Author priorities | Shipped priorities |
|---|---|---|
| RaySense - Cover Animation (38 submods) | 2110000000–231 | 2140000000–231 |
| Sonder's Raysense Wall Leaning (8) | 7005000–007 | 2130000100–107 |
| Simple Wall Lean (RaySense) (4) | 2078869540–546 | 2130000000–006 |

Each author's internal order is kept by a constant offset. Cover sits above the wall leans, so
leaving cover beside a wall plays the cover exit, not a lean.

## Why

These mods replace `mt_idle`, the weapon idles (`1hm/2hm/2hw/bow_idleheld/staff/mlh/mrh_idle`)
and the sneak idles. A scan of the Ultra profile's OAR/DAR virtual file system (2026-10-18) found
these as the top competitors on those clips: Beam Walking Assist at 2110000080–084, then RaySense
Edge Lookdown at 2110000070–071, then UNDERDOG at 2000000xxx and EVG Conditional Idles at ~86M.
Before this patch, Cover's `2110000000–069` submods (sneak loops/enters/exits, front-hide) ranked
below Beam Walking and Edge Lookdown. **Sonder's whole set at 7005000 lost to EVG and UNDERDOG,
so it could never play.** The new bands sit above Beam Walking too. On a fence, Beam Walking's
conditions and the wall sensors rarely overlap.

## Mechanism

An OAR `user.json` beside a submod's `config.json` **replaces** that config (same pattern as
[`DynamicDodgeNoSway`](DynamicDodgeNoSway.md)). Each file is the author's `config.json` verbatim
with only `priority` changed. None of the three mods ships a `user.json`, so MO2 placement doesn't
matter. The exception is OAR's in-game editor, which also writes `user.json` into MO2's
`overwrite` and would beat these.

Generated by `src/RaySensePriority/tools/01-raise-raysense-priority.py` from the installed mods.
It asserts each author priority falls inside the expected band and the submod counts (38/8/4),
so an upstream update fails loudly instead of shipping stale configs. Rerun it after updating any
of the three mods.
